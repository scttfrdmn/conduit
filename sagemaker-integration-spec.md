## Overview

### SageMaker Ecosystem Priority

**Priority 1: SageMaker Studio Lab** (Week 8)
- Free, no AWS account required
- 12hr CPU / 4hr GPU sessions
- 15GB persistent storage
- Perfect for tutorials, demos, learning
- **Entry point to AWS ecosystem**

**Priority 2: SageMaker Studio** (Week 8)
- Full AWS account with IAM
- Production IDE environment
- Unlimited compute (user pays)
- MLOps integration
- **Production environment**

**Priority 3: SageMaker Notebook Instances** (Week 9)
- Classic notebook experience
- Backward compatibility
- Some users still prefer it
- **Legacy support**

**Priority 4: Google Colab** (Week 10+)
- Fallback for non-AWS users
- Academic/educational reach
- Not emphasized in docs

### Strategic Funnel

```
Studio Lab (Free)
    ↓
"Try it free - no account needed"
    ↓
Deploy to Bedrock → Creates AWS resources
    ↓
"Upgrade to Studio for production"
    ↓
SageMaker Studio (Paid)
    ↓
Full AWS ecosystem
```

## Integration Architecture

### Credential Management

```python
# internal/aws/credentials.go
package aws

import (
    "context"
    "os"
    
    "github.com/aws/aws-sdk-go-v2/config"
)

type EnvironmentType string

const (
    EnvStudioLab        EnvironmentType = "studio-lab"
    EnvStudio           EnvironmentType = "studio"
    EnvNotebookInstance EnvironmentType = "notebook-instance"
    EnvLocal            EnvironmentType = "local"
)

// DetectEnvironment determines where code is running
func DetectEnvironment() EnvironmentType {
    // Check for SageMaker Studio
    if os.Getenv("SAGEMAKER_INTERNAL_IMAGE_URI") != "" {
        // Further check if Studio Lab vs Studio
        if os.Getenv("STUDIO_LAB_USER_ID") != "" {
            return EnvStudioLab
        }
        return EnvStudio
    }
    
    // Check for Notebook Instance
    if os.Getenv("SM_TRAINING_ENV") != "" {
        return EnvNotebookInstance
    }
    
    return EnvLocal
}

// GetAWSConfig returns appropriate AWS config based on environment
func GetAWSConfig(ctx context.Context) (aws.Config, error) {
    env := DetectEnvironment()
    
    switch env {
    case EnvStudio, EnvNotebookInstance:
        // Use SageMaker execution role automatically
        return config.LoadDefaultConfig(ctx)
        
    case EnvStudioLab:
        // Studio Lab: Need user to configure credentials
        // But can deploy to their AWS account if they provide them
        return config.LoadDefaultConfig(ctx)
        
    case EnvLocal:
        // Local: Use standard AWS credential chain
        return config.LoadDefaultConfig(ctx)
    }
    
    return config.LoadDefaultConfig(ctx)
}

// GetExecutionRole returns SageMaker execution role if available
func GetExecutionRole() (string, error) {
    env := DetectEnvironment()
    
    switch env {
    case EnvStudio, EnvNotebookInstance:
        // Get from SageMaker metadata
        // This is simplified - actual implementation would use SageMaker SDK
        return os.Getenv("SAGEMAKER_ROLE_ARN"), nil
        
    default:
        return "", fmt.Errorf("not running in SageMaker environment")
    }
}
```

### Python SDK Integration

```python
# conduit_sdk/environment.py
import os
import boto3
from enum import Enum

class Environment(Enum):
    STUDIO_LAB = "studio-lab"
    STUDIO = "studio"
    NOTEBOOK_INSTANCE = "notebook-instance"
    LOCAL = "local"

def detect_environment() -> Environment:
    """Detect where code is running"""
    
    if os.getenv('SAGEMAKER_INTERNAL_IMAGE_URI'):
        if os.getenv('STUDIO_LAB_USER_ID'):
            return Environment.STUDIO_LAB
        return Environment.STUDIO
    
    if os.getenv('SM_TRAINING_ENV'):
        return Environment.NOTEBOOK_INSTANCE
    
    return Environment.LOCAL

def get_execution_role() -> str:
    """Get SageMaker execution role if available"""
    
    env = detect_environment()
    
    if env in [Environment.STUDIO, Environment.NOTEBOOK_INSTANCE]:
        import sagemaker
        return sagemaker.get_execution_role()
    
    return None

def get_region() -> str:
    """Get AWS region"""
    
    # Try SageMaker environment variable first
    region = os.getenv('AWS_REGION')
    if region:
        return region
    
    # Fall back to boto3
    session = boto3.Session()
    return session.region_name

# conduit_sdk/model.py
class Model:
    def deploy_to_bedrock(self, **kwargs):
        """Deploy to Bedrock with automatic credential handling"""
        
        env = detect_environment()
        
        if env == Environment.STUDIO_LAB:
            # Prompt user to configure AWS credentials
            if not self._has_aws_credentials():
                print("""
⚠️  AWS credentials not configured

To deploy to Bedrock:
1. Click 'AWS' in Studio Lab menu
2. Enter your AWS Access Key ID and Secret
3. Run this cell again

Or try the public demo endpoint:
  model.predict_public({...})
""")
                return None
        
        elif env in [Environment.STUDIO, Environment.NOTEBOOK_INSTANCE]:
            # Automatically use SageMaker execution role
            if 'role' not in kwargs:
                kwargs['role'] = get_execution_role()
        
        # Deploy with appropriate credentials
        return self._deploy_to_bedrock_internal(**kwargs)
    
    def deploy_to_sagemaker(self, **kwargs):
        """Deploy as SageMaker endpoint"""
        
        env = detect_environment()
        
        if env not in [Environment.STUDIO, Environment.NOTEBOOK_INSTANCE]:
            raise ValueError("SageMaker deployment only available in SageMaker environments")
        
        if 'role' not in kwargs:
            kwargs['role'] = get_execution_role()
        
        # Deploy using SageMaker SDK
        return self._deploy_to_sagemaker_internal(**kwargs)
```

### Notebook Generator

```go
// internal/notebooks/sagemaker.go
package notebooks

import (
    "github.com/yourusername/conduit/pkg/types"
)

type SageMakerNotebookGenerator struct {
    model    *types.Model
    platform string // "studio-lab", "studio", "notebook-instance"
}

func (g *SageMakerNotebookGenerator) Generate() (*Notebook, error) {
    cells := []Cell{}
    
    // Environment detection cell
    cells = append(cells, g.environmentDetectionCell())
    
    // Install cell
    cells = append(cells, g.installCell())
    
    // Import cell
    cells = append(cells, g.importCell())
    
    // Load model cell
    cells = append(cells, g.loadModelCell())
    
    switch g.platform {
    case "studio-lab":
        cells = append(cells, g.studioLabDeployCell())
        cells = append(cells, g.upgradePromptCell())
    case "studio":
        cells = append(cells, g.studioDeployCell())
        cells = append(cells, g.modelRegistryCell())
    case "notebook-instance":
        cells = append(cells, g.notebookInstanceDeployCell())
    }
    
    // Inference cell
    cells = append(cells, g.inferenceCell())
    
    // Visualization cell
    cells = append(cells, g.visualizationCell())
    
    return &Notebook{
        Cells:    cells,
        Metadata: g.metadata(),
    }, nil
}

func (g *SageMakerNotebookGenerator) studioLabDeployCell() Cell {
    return Cell{
        Type: "code",
        Source: []string{
            "# Deploy to Bedrock\n",
            "# Note: This creates resources in your AWS account\n",
            "\n",
            "endpoint = model.deploy_to_bedrock(\n",
            "    instance_type=\"ml.g5.2xlarge\",\n",

            ")\n",
            "\n",
            "print(f\"✓ Deployed to: {endpoint.endpoint_name}\")\n",

}

            "\n",
            "Click **'Upgrade to Studio'** in the Studio Lab menu.\n",

}
```

## Summary

### The Strategy

**Entry:** SageMaker Studio Lab (free, no AWS account)
**Growth:** Deploy to Bedrock (need AWS account)
**Production:** SageMaker Studio (full MLOps)
**Retention:** AWS ecosystem lock-in

### Why This Works

1. **Lower barrier** than full AWS account
2. **AWS-native** from day one
3. **Natural upgrade path** to production
4. **Better than Colab** (persistent storage, AWS integration)
5. **Drives AWS revenue** (Bedrock, SageMaker)

### Key Differentiator

*"We're the only platform optimized for the full SageMaker ecosystem - from learning (Studio Lab) to production (Studio) to deployment (Bedrock)."*

---

**This is the right priority.** Keep users in AWS from the start, create clear upgrade paths, and drive both Studio Lab adoption (helps AWS) and Bedrock revenue (helps AWS). Colab is just a checkbox for non-AWS users.
